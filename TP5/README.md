### Resumo:
    1. Configurar o json-server utilizando o ficheiro cinema.json como base de dados
     2. Desenvolver uma aplicação web em Express que disponibilize as seguintes rotas:
     	a. GET / ou /filmes => apresenta id, título, ano, quantidade de géneros associados e número de atores do filme;
     	b. GET /filmes/:id => exibe todas as informações detalhadas de um filme;
     	c. GET /atores => mostra uma tabela com cada ator e a contagem de filmes em que participa;
     	d. GET /atores/:id => página individual do ator com todos os seus dados;
     	extra. funcionalidade equivalente aplicada aos géneros
